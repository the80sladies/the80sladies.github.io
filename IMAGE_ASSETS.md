# The 80s Ladies Image Asset Guide

The site has been wired for image-ready sections. Add the selected images into the `images/` folder using these exact file names:

```text
images/homepage-hero-banner.png
images/shop-big-hair-shirt.png
images/about-hairspray-profile.png
images/max-volume-poster.png
images/club-logo.png
```

## Recommended placements

- `homepage-hero-banner.png` — wide homepage hero/banner image.
- `shop-big-hair-shirt.png` — featured shop image and shirt/product card.
- `about-hairspray-profile.png` — About page/profile-style circular image.
- `max-volume-poster.png` — blog/video visual for big hair and hairspray content.
- `club-logo.png` — About page brand badge or future club section.

## Notes

The HTML and CSS already reference these image names. If an image is not uploaded yet, the site still uses the neon fallback styling and remains usable.

For best performance, keep images web-friendly:

- Use `.png` for logos or transparent artwork.
- Use `.jpg` only if you also change the references in the HTML.
- Try to keep large images under 500 KB when possible.
- Wide hero images should be about 1600 × 900 or similar.
- Product/mockup images can be square or vertical.
